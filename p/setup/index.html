제일 먼저 바꿀 설정 5개

설정은 왼쪽 아래 내 이름(이니셜) → 설정에 모여 있어요. 메뉴 이름은 앱 버전·언어 설정에 따라 조금 다를 수 있어서 영어 이름도 같이 적어 뒀어요.

① 내 대화 학습에 안 쓰이게

설정 › 개인정보 보호(Privacy)로 가요. 웹은 주소창에 claude.ai/settings/data-privacy-controls 를 입력해도 바로 열려요.

AI 모델 개선 돕기(Help improve our AI models)를 끄기.

끄면 새 대화와 코딩 세션이 앞으로의 모델 학습에 쓰이지 않아요. 이미 시작된 학습이나 이미 만들어진 모델에는 적용되지 않아요. 안전 검토에 걸린 대화는 안전 연구에 쓰일 수 있어요.

② 지시사항: 나를 한 번만 소개

설정 › 내 Claude(Your Claude) › 지시사항(Instructions). 예전 화면에서는 '계정' 안에 있어요.

직업·원하는 말투·답 형식을 적어요. 적어 둔 내용은 모든 대화에 반영돼요. 아래 문구를 복사해서 내 상황에 맞게 고쳐 쓰세요.

③ 메모리: 기억 점검하기

설정 › 내 Claude에서 대화에서 메모리 생성(Generate memory from chats)이 켜져 있는지 확인해요. 무료 플랜도 기본으로 켜져 있어요.

Claude가 나에 대해 기억하는 내용을 열어 보고, 틀린 건 지우거나 고쳐요. 새 메모리를 그만 만들고 싶으면 일시 중지할 수 있어요.

지난 대화 검색(Search and reference chats)은 유료 플랜 기능이에요. 민감한 주제를 메모리에 넣는 옵션은 기본으로 꺼져 있어요.

④ 코드 실행 및 파일 생성 켜기

설정 › 기능(Capabilities) › 코드 실행 및 파일 생성(Code execution and file creation) 켜기. 웹은 claude.ai/settings/capabilities.

이제 "표로 정리해서 엑셀 파일로 줘"처럼 부탁하면 엑셀·워드·PPT·PDF 파일로 바로 받아요. 보통 기본으로 켜져 있지만 계정마다 달라서 한 번 확인해 두세요.

⑤ 웹 검색 켜기

채팅 입력창 왼쪽 아래 + 버튼 → 웹 검색(Web search)을 눌러 체크 표시가 생기게 해요.

새 Claude 화면에서는 이 버튼이 없고, 필요할 때 알아서 검색해요. 무료 플랜도 쓸 수 있고, 검색도 사용량 한도에 포함돼요.

복사해서 쓰는 지시사항 문구

① 직장인 기본형나는 [직무]로 일하는 직장인이야. 답은 결론부터 3줄 안으로 쓰고, 비교가 필요하면 표로 정리해 줘. 모르는 건 모른다고 말해 줘.
② 말투 고정존댓말 해요체로, 어려운 용어는 괄호 안에 쉬운 말로 풀어 줘. 이모지는 쓰지 마.
③ 글쓰기 도우미내가 쓴 글을 고칠 때는 원래 뜻과 길이를 유지하고, 바꾼 부분만 굵게 표시해 줘. 고친 이유는 마지막에 한 줄씩만.
④ 공부·자기계발새로운 개념을 설명할 때는 쉬운 예시 하나 → 핵심 정리 3줄 → 확인 질문 1개 순서로 알려 줘.
⑤ 반대 의견 받기내 계획이나 의견에 무조건 맞장구치지 말고, 약점 2개와 더 나은 대안 1개를 꼭 같이 말해 줘.

알아 두면 좋은 점

지시사항에는 주민등록번호·주소·회사 기밀 같은 정보는 적지 마세요. 직무와 원하는 답 형식이면 충분해요.
